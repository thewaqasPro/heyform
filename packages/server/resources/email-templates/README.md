# Email templates

| Name                            | Description                                               |
|:--------------------------------|:----------------------------------------------------------|
| account_deletion_request        | Verification code for account deletion                    |
| schedule_account_deletion_alert | Notify users that their account is scheduled for deletion |
| account_deletion_alert          | Notify users that their account has been deleted          |
| email_verification_request      | Verification code to verify new user's email address      |
| password_change_alert           | Notify users that their password has been updated         |
| team_invitation                 | Invitation to collaborate on a KyndForm workspace         |
| team_deletion_alert             | Notify users that their workspace has been deleted        |
| team_deletion_request           | Verification code for workspace deletion                  |
| project_deletion_alert          | Notify users that their project has been deleted          |
| project_deletion_request        | Verification code for project deletion                    |
| submission_notification         | Notify workspace members when a new form submission arrives |
| welcome                         | Welcome email for new KyndForm users                      |
